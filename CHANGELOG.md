# История изменений

## 5.0.0

- Игровой API отдаёт пакеты без ответов. Правильный ответ открывается после отправки выбранного варианта, а сервер сам считает результат раунда и обновляет статистику.
- Добавлен поиск по исполнителям, альбомам и трекам с учётом диакритики, пунктуации, цифр и транслита.
- Для названий длиннее пяти букв поиск и проверка ответа учитывают расстояние Левенштейна до единицы.

## 4.1.0

- Исполнителей, треки и альбомы можно удалить из каталога с очисткой их данных. Совместные записи остаются у других исполнителей.
- Связанные вопросы сохраняют номера и показывают «Вопрос был удалён». Подсказки, ответы и ссылки на медиа очищаются, а счётчики каталога пропускают такие вопросы.

## 4.0.0

- Клипы подготавливаются в фоне после создания пакета. API выдаёт аудио после сохранения клипа, а игровому каталогу доступны только полностью готовые пакеты.
- У пакетов и вопросов появились статусы `new`, `pending` и `ready`. API возвращает счётчик готовых клипов и поддерживает повтор подготовки после ошибки.
- Существующие звуковые пакеты автоматически возвращаются в каталог после проверки сохранённых клипов и подготовки недостающих.

## 3.1.0

- Добавлено хранение медиатеки в приватном бакете Yandex Object Storage. Текущие URL файлов, проверка доступа и перемотка аудио сохраняются.
- Добавлена команда переноса медиатеки с проверкой контрольных сумм объектов и обновлением ссылок в PostgreSQL одной транзакцией.
- Раздел «Хранилище» поддерживает просмотр, привязку и удаление файлов в S3.

## 3.0.0

- Добавлены модерация обложек, маски и их серверная отрисовка для раунда угадывания исполнителя.
- Игровой API больше не передаёт идентификаторы альбомов и оригинальных обложек в вопросах. Старым пакетам необходимы одобренные обложки.
- Очередь модерации поддерживает случайный порядок с чередованием исполнителей.
- Для раунда по гласным выбираются треки с согласными, подсказки формируются строчными буквами без подчёркиваний.

## 2.1.0

- Добавлен справочник тегов с переносом существующих тегов исполнителей и квиз-пакетов.
- Теги можно назначать альбомам и трекам. Переименование обновляет связанные записи, а удалить можно только неиспользуемый тег.

## 2.0.0

- Добавлены сохранение результатов раунда и автоматическое обновление известности и числа показов.
- Оценки каталога поддерживают дробные значения; выбор вопросов учитывает тип медиа и треки без альбома.
- Миграция удаляет прежние пакеты, раунды и вопросы; каталог и медиа сохраняются.

## 1.1.0

- Добавлены поиск, сортировка и фильтрация каталога по статусу аудио.
- Добавлена ручная загрузка изображений и MP3 с сохранением пользовательских изменений при импорте.
- Новые вопросы используют последнюю загруженную вручную запись трека.

## 1.0.1

- Список исполнителей возвращается от новых к старым.
- Изображения, записи и аудиофрагменты сохраняются в отдельных каталогах.

## 1.0.0

- Добавлены HTTP API и хранение каталога исполнителей, альбомов и треков.
- Добавлены импорт данных, загрузка медиа и управление настройками.
- Добавлена генерация квиз-пакетов с раундами и аудиофрагментами.
