# История изменений

## 3.0.0

- Добавлены модерация обложек, маски и их серверная отрисовка для раунда угадывания исполнителя.
- Игровой API больше не передаёт идентификаторы альбомов и оригинальных обложек в вопросах. Старым пакетам необходимы одобренные обложки.
- Очередь модерации поддерживает случайный порядок с чередованием исполнителей.
- Для раунда по гласным выбираются треки с согласными, подсказки формируются строчными буквами без подчёркиваний.

## 2.1.0

- Добавлен справочник тегов с переносом существующих тегов исполнителей и квиз-пакетов.
- Теги можно назначать альбомам и трекам. Переименование обновляет связанные записи, а удалить можно только неиспользуемый тег.

## 2.0.0

- Добавлены сохранение результатов раунда и автоматическое обновление известности и числа показов.
- Оценки каталога поддерживают дробные значения; выбор вопросов учитывает тип медиа и треки без альбома.
- Миграция удаляет прежние пакеты, раунды и вопросы; каталог и медиа сохраняются.

## 1.1.0

- Добавлены поиск, сортировка и фильтрация каталога по статусу аудио.
- Добавлена ручная загрузка изображений и MP3 с сохранением пользовательских изменений при импорте.
- Новые вопросы используют последнюю загруженную вручную запись трека.

## 1.0.1

- Список исполнителей возвращается от новых к старым.
- Изображения, записи и аудиофрагменты сохраняются в отдельных каталогах.

## 1.0.0

- Добавлены HTTP API и хранение каталога исполнителей, альбомов и треков.
- Добавлены импорт данных, загрузка медиа и управление настройками.
- Добавлена генерация квиз-пакетов с раундами и аудиофрагментами.
